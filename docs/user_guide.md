# User Guide

## Назначение

AdResponse помогает рекламному агентству подготовить первичный ответ на клиентское обращение. Сервис сохраняет сообщение, определяет категорию и эмоциональный тон, выбирает подготовленные комментарии менеджера и формирует безопасный ответ без обещаний цен, сроков и гарантированных результатов.

## Клиентский чат

1. Откройте `/chat/`.
2. Введите сообщение клиента.
3. Нажмите `Отправить`.
4. Дождитесь ответа системы.
5. Проверьте боковую панель: там отображаются категория, эмоциональный тон и рекомендация по передаче менеджеру.

Примеры сообщений:

- `Сколько стоит запуск рекламы для салона красоты?`
- `Хотим запустить рекламную кампанию для новой услуги.`
- `Мы недовольны результатами, заявок почти нет.`

## Панель менеджера

1. Откройте `/manager/`.
2. Посмотрите список обращений.
3. При необходимости используйте фильтры по статусу, категории и эмоциональному тону.
4. Откройте обращение.
5. Нажмите `Принять обращение`.
6. Введите ручной ответ менеджера.
7. Измените статус обращения, если требуется.

Все сообщения клиента, системы и менеджера сохраняются в одной истории диалога.

## Админ-раздел базы знаний

1. Откройте `/admin/knowledge-base`.
2. Для новой категории нажмите `Добавить` в блоке категорий.
3. Для нового подготовленного комментария нажмите `Добавить` в блоке комментариев.
4. Выберите категорию, эмоциональный тон, укажите заголовок, текст, приоритет и активность.
5. Сохраните форму.

Активные комментарии используются при генерации ответа. Чем меньше значение приоритета, тем выше комментарий в выдаче.

## Fallback mode

Fallback mode работает без `llama.cpp`. Он использует локальные правила:

- классификация по ключевым словам;
- анализ тональности по ключевым словам;
- выбор комментариев из базы знаний;
- уточняющие вопросы;
- рекомендация передачи менеджеру для сложных или негативных обращений.

## llama.cpp mode

Если включить `USE_LLAMA=true`, система попробует сформировать ответ через локальный `llama.cpp`. Если сервер недоступен или возвращает ошибку, клиент все равно получит fallback-ответ.
