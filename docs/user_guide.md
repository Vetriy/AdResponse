# User Guide

## Назначение

AdResponse помогает рекламному агентству подготовить первичный ответ на клиентское обращение. Сервис сохраняет сообщение, определяет категорию и эмоциональный тон, выбирает подготовленные комментарии менеджера и формирует безопасный ответ без обещаний цен, сроков и гарантированных результатов.

## Вход и роли

Открытые страницы:

- `/` - главная;
- `/login` - вход;
- `/register` - регистрация клиента.

Демо-пользователи после `python3 -m app.db.seed`:

| Логин | Пароль | Роль |
| --- | --- | --- |
| `admin` | `admin123` | `admin` |
| `manager` | `manager123` | `manager` |
| `client` | `client123` | `client` |

Чтобы переключиться между ролями, нажмите `Выход` и войдите под другим пользователем.

Регистрация открыта только для клиентов. Менеджеров и администраторов создает администратор в разделе пользователей.

## Клиентский чат

1. Войдите как `client`.
2. Откройте `/chat/` или `/client/chat`, чтобы создать новое обращение.
3. Введите сообщение клиента.
4. Нажмите `Отправить`.
5. Дождитесь ответа системы.
6. Проверьте боковую панель: там отображаются категория, эмоциональный тон и рекомендация по передаче менеджеру на русском языке.

В кабинете `/client/dashboard` отображается список обращений клиента. Чтобы продолжить старый диалог, откройте конкретное обращение из списка и отправьте сообщение на странице `/client/appeals/{appeal_id}`. Кнопка `Новое обращение` всегда запускает отдельную новую переписку.

К сообщению можно прикрепить изображение или документ до 10 МБ: `.png`, `.jpg`, `.jpeg`, `.webp`, `.pdf`, `.doc`, `.docx`, `.xls`, `.xlsx`, `.txt`. Файлы сохраняются локально и отображаются в истории диалога.

Если менеджер загрузил рекламный отчет, в кабинете появится блок `Отчеты по рекламе`. Отчет можно открыть или нажать `Задать вопрос`, чтобы создать обращение с контекстом этого отчета.

Примеры сообщений:

- `Сколько стоит запуск рекламы для салона красоты?`
- `Хотим запустить рекламную кампанию для новой услуги.`
- `Мы недовольны результатами, заявок почти нет.`

## Панель менеджера

1. Войдите как `manager` или `admin`.
2. Откройте `/manager/dashboard`.
3. Посмотрите единый список обращений и идентификатор клиента в каждой строке.
4. При необходимости используйте фильтры по статусу, категории и эмоциональному тону. Значения отображаются на русском языке.
5. Откройте обращение.
6. Нажмите `Принять обращение`. Это закрепляет диалог за текущим менеджером и показывает, кто взял обращение в работу.
7. Введите ручной ответ менеджера.
8. При необходимости прикрепите файл к ручному ответу.
9. Измените статус обращения, если требуется.
10. В деталях обращения можно загрузить рекламный отчет для клиента: укажите название, описание и файл отчета.

Все сообщения клиента, системы и менеджера сохраняются в одной истории диалога.
Технические источники автоответов не показываются как коды: `local_rules` отображается как `Автоматический ответ`, `local_llama_cpp` - как `Локальная языковая модель`.

## Админ-раздел базы знаний

1. Войдите как `admin`.
2. Откройте `/admin/knowledge-base`.
3. Проверьте широкий блок подготовленных комментариев и блок категорий ниже.
4. Для новой категории нажмите `Добавить` в блоке категорий.
5. Для нового подготовленного комментария нажмите `Добавить` в блоке комментариев.
6. Выберите категорию, эмоциональный тон, укажите заголовок, текст, приоритет и активность.
7. Сохраните форму.

Активные комментарии используются при генерации ответа. Чем меньше значение приоритета, тем выше комментарий в выдаче.

Верхняя навигация администратора содержит основные разделы: `Главная`, `Админ`, `Пользователи`, `База знаний`, `Выход`.
На `/admin/dashboard` отображаются статистические карточки: пользователи, клиенты, менеджеры, администраторы, обращения, обращения с вниманием менеджера, закрытые обращения, подготовленные комментарии и загруженные отчеты.

## Управление пользователями

1. Войдите как `admin`.
2. Откройте `/admin/users`.
3. Создайте пользователя с ролью `Клиент`, `Менеджер` или `Администратор`. В базе сохраняются внутренние значения `client`, `manager`, `admin`.
4. При необходимости отредактируйте данные, сбросьте пароль или выключите пользователя.

## Fallback mode

Fallback mode работает без `llama.cpp`. Он использует локальные правила:

- классификация по ключевым словам;
- анализ тональности по ключевым словам;
- выбор комментариев из базы знаний;
- уточняющие вопросы;
- рекомендация передачи менеджеру для сложных или негативных обращений.

## llama.cpp mode

Если включить `USE_LLAMA=true`, система попробует сформировать ответ через локальный `llama.cpp`. Если сервер недоступен или возвращает ошибку, клиент все равно получит fallback-ответ.
